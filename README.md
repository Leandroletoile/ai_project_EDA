# EDA COVID-19 - Estados Unidos

## Descripcion

Proyecto de analisis exploratorio de datos desarrollado durante la formacion en AI Engineering de Factoria F5.

El objetivo es estudiar la evolucion de la pandemia de COVID-19 en Estados Unidos, identificar patrones temporales, comparar estados y analizar la calidad de los datos.

## Dataset

Fuente: COVID Tracking Project.
https://api.covidtracking.com/v1/states/daily.json

## Tecnologias

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- JupyterLab
- SciPy
- Pytest

## Estructura

- data/raw: datos originales.
- data/processed: datos procesados.
- notebooks: analisis exploratorio.
- src: codigo reutilizable.
- reports: informes y graficos.
- tests: pruebas automatizadas.

## Instalacion

Crear entorno virtual: python -m venv .venv

Activar: .venv\Scripts\Activate.ps1

Instalar dependencias: pip install -r requirements.txt

Ejecutar: jupyter lab
